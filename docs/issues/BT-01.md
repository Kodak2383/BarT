# BT-01 — Ship the licences

**Mode:** 🤖 AFK · **needs:** — · **blocks:** BT-02, BT-14

## Why
Substantial parts of `Bridging.swift`, `EventTap.swift` and the `scromble` technique come from
[Ice](https://github.com/jordanbaird/Ice) (MIT). MIT requires the copyright notice and licence
text to ship with the distribution. There is no LICENSE file at all today — irrelevant for a
private tool, a licence condition for a public release (PRD §2).

## Slice
Repo files + about panel. No engine work.

## Visible result
The about panel has an "Acknowledgements" entry that opens the third-party notice.

## Done when
- `LICENSE` (MIT, André Duhme) in the repo root.
- `THIRD-PARTY-LICENSES.md` with Ice's copyright line and full MIT text.
- Both linked from `README.md`; the about panel links to the third-party file.

## Files
`LICENSE`, `THIRD-PARTY-LICENSES.md`, `README.md`, `BarT/App/AppDelegate.swift`
