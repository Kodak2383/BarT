# BT-01 — Ship the licences

**Mode:** 🤖 AFK · **needs:** — · **blocks:** BT-02, BT-14

## Why
BarT takes code from [Ice](https://github.com/jordanbaird/Ice), which is **GPL-3.0** — not MIT, as
six source comments, the README and the first version of this issue claimed. GPL-3 is copyleft, so
distributing BarT means distributing it under the same licence, with the notices attached.

## Slice
Repo files + the about panel.

## Visible result
The about panel states the licence and Ice's role; the repo carries both licence files.

## Done when
- [x] `LICENSE` holds the full GPL-3.0 text.
- [x] `THIRD-PARTY-LICENSES.md` names Ice, its copyright and licence, and lists every place its
      code appears in BarT.
- [x] The README has a Licence section pointing at both.
- [~] The about panel shows the notice (`orderFrontStandardAboutPanel(options: [.credits:])`) —
      code in place, but **unverified**: the status menu is only attached for the duration of a
      right-click, so it cannot be opened by script. Needs one look from a human.
- [x] Every "MIT" claim in the source is corrected — verified by grep.
