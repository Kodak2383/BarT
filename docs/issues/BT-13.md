# BT-13 — Accessibility names for the two tabs

**Mode:** 🤖 AFK · **needs:** — · **blocks:** BT-14

## Why
The tabs announce themselves to the accessibility API as "radio button 1" and "radio button 2" —
in an app whose own core feature depends on other apps' accessibility names. Measured, not assumed:
`System Events` reports them unnamed today.

## Slice
Two accessibility labels.

## Visible result
`osascript -e 'tell application "System Events" to tell process "BarT" to get name of every radio
button of tab group 1 of group 1 of window 1'` returns the tab names.

## Done when
Both tabs report "General" and "Items"; VoiceOver announces them.

## Files
`BarT/UI/SettingsView.swift`
