# BT-09 — Drag icons between sections

**Mode:** 👤 HITL — *real drags across your menu bar; whether it feels right is your call*
**needs:** BT-08 · **blocks:** BT-14

## Why
The gesture the grid invites. Deliberately after BT-08 so the keyboard path exists first.

## Slice
UI gesture → `moveItem` → engine → real menu bar.

## Visible result
Drag an icon from "Visible" into "Hidden" and watch it leave the menu bar.

## Done when
- Dragging between all three sections works, including into an empty section.
- The target section highlights while hovered.
- Dropping into the current section is a no-op, not a queued drag.
- Reordering within a section remains unsupported (PRD §3.2).
- A failed drag surfaces through the BT-10 message, not silently.

## Files
`BarT/UI/SettingsView.swift`

## Acceptance needs you to
Judge the feel: does the highlight read, does the bar keep up, does anything oscillate.
