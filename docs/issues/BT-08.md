# BT-08 — Context menu and accessible icons

**Mode:** 🤖 AFK — *verifiable by script via System Events*
**needs:** BT-07 · **blocks:** BT-09

## Why
With the pickers gone, dragging would be the only way to move an item — unusable by keyboard and
VoiceOver. This is the accessibility floor for a public release, not a nicety (R4-Q2).

## Slice
UI + accessibility metadata.

## Visible result
Right-click any icon: a menu with the three sections, the current one marked. Tab reaches the
icons; VoiceOver announces the item's name.

## Done when
- Right-click and the keyboard context-menu key both open the menu.
- Choosing a section calls `moveItem` — same path as every other route.
- Every icon carries an accessibility label (its display name) and is focusable.
- `System Events` reports the icons by name, not as anonymous groups.
