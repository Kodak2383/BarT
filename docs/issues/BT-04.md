# BT-04 — Welcome window on first launch

**Mode:** 👤 HITL — *the system permission dialog needs your click*
**needs:** BT-03 · **blocks:** BT-05

## Why
BarT starts, places its icon, and does nothing. The route to the permission is right-click →
Settings → General, and nobody finds that unaided (PRD §3.1).

## Slice
First-run detection → new window → permission request → menu entry.

## Visible result
Delete the defaults domain, launch: a window explains BarT in two sentences and offers one button.

## Done when
- Appears on first launch only (flag in `UserDefaults`), reachable afterwards from the status menu.
- Two sentences: what BarT does, why it needs accessibility.
- One button triggering the system dialog; the window reacts to the granted state (BT-03).
- States that updates invalidate the permission (PRD §2).
- Does not ask for screen recording — that belongs to BT-06.

## Files
new `BarT/UI/WelcomeView.swift`, `BarT/App/AppDelegate.swift`

## Acceptance needs you to
Click through the real system dialog once. I can reset first-run state myself
(`defaults delete de.andreduhme.BarT`).
