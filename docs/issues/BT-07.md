# BT-07 — The section grid replaces the list

**Mode:** 🤖 AFK — *I can screenshot the window myself; your taste check is welcome, not required*
**needs:** BT-06 · **blocks:** BT-08, BT-10

## Why
22 near-identical rows with identical pickers read as a database table. Three grids of real icons
read as "this is my menu bar" (PRD §3.2, R3-Q2).

## Slice
UI only — the data already flows after BT-06.

## Visible result
Three labelled areas of icons instead of a text list.

## Done when
- Each section is a grid that wraps onto further rows as needed (R4-Q1) — no horizontal scrolling.
- Per-row pickers are gone; section explanations stay.
- An empty section says so and keeps its area.
- Window sizes sensibly at 8 items and at 40; the window minimum is adjusted.
- Items **cannot** be reordered within a section — that stays unsupported (PRD §3.2).
