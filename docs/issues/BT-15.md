# BT-15 — Remove the Ice-derived drag engine

**Mode:** 🤖 AFK · **needs:** — · **blocks:** BT-02, BT-03, BT-04, BT-06, BT-07, BT-16, BT-14

## Why
`scromble`, the event tap and the CGS signatures come from Ice (GPL-3.0). Removing them frees the
licence, drops the accessibility permission, and deletes the most fragile part of the app (see
PRD §7). What goes with it is automatic arranging — deliberately (PRD §3.2).

## Slice
Engine, controller, model and UI shrink together. This is a deletion, not a rewrite.

## Visible result
BarT still collapses and reveals exactly as before. Nothing else changes for the user — because
everything that changes was machinery they never saw.

## Goes away
- `BarT/Engine/EventTap.swift` — whole file
- `DragHideEngine`: `move(_:to:)`, `scromble(_:pid:)`, the `CGEvent` window-ID fields, everything
  that posts events. **Keeps** the separators, their widths, `reveal`, and `placement(of:)`
- `OscillationGuard` — it exists only because drags disturb neighbouring items
- `MenuBarLayout`, `LayoutStore` — the section of an item is now read from its position relative
  to the separators, not stored
- `MenuBarController.moveItem(_:to:)` and the reconcile loop
- The accessibility permission and everything around it (`AccessibilityPermission`, the owner
  lookup in `MenuBarItemSource` that needed it)
- From `Bridging.swift`: whatever only the drags used. Verify each remaining declaration is still
  called — the window list and frame lookups stay.

## Stays
Separators, reveal/collapse, the outside-click monitor, auto-collapse, the hotkey, item
enumeration through the CGS window list (which needs no permission).

## Done when
- `grep -rn "Ice" BarT/` returns nothing but, at most, a historical note — and
  `THIRD-PARTY-LICENSES.md` is updated to say the code is gone.
- The app builds, `scripts/gates.sh` passes, and reveal/collapse still work — verified the way
  BT-12 was: capture the status icon before, during and after.
- No file mentions an accessibility permission any more.
- `MenuBarLayout.runSelfTest()` either still applies or is removed with its type; the self-test
  suite must not silently shrink to nothing without saying so in the commit message.

## Files
`BarT/Engine/*`, `BarT/Model/*`, `BarT/Services/LayoutStore.swift`, `BarT/Permissions/*`,
`BarT/UI/SettingsView.swift`, `BarT/App/AppDelegate.swift`, `THIRD-PARTY-LICENSES.md`

## Careful
This deletes the work of several sessions. The separator mechanism is *not* from Ice and must
survive intact — it is the product. Do it in one commit that only removes, so it can be reverted
in one step if the assertion engine later wants pieces back.
