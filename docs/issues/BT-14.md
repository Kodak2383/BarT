# BT-14 — Publish 1.0

**Mode:** 👤 HITL — *your GitHub account, and a machine that is not this one*
**needs:** BT-01 … BT-13 · **blocks:** —

## Why
Everything ships at once (PRD §3, R5-Q3). This is the step that makes it downloadable — and the
first honest test of the permission and Gatekeeper chain, which cannot be tested on the machine
that built it.

## Slice
Build → repo → release → install on a clean account.

## Visible result
A stranger downloads a zip and reaches a working BarT without asking you anything.

## Done when
- Release build produced and zipped; CI green.
- Repo has a remote and is public, with LICENSE and third-party notices visible.
- Release notes cover the Gatekeeper path and the permissions-on-update caveat.
- README screenshot shows the finished grid view.
- **A fresh user account (or another Mac) installs from that link and reaches a working state** —
  including both permission prompts — without any step that is not in the README.

## Files
`.github/workflows/build.yml`, `README.md`

## Acceptance needs you to
Create the remote, publish, and run the clean-account install.
