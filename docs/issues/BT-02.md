# BT-02 — README for a public audience

**Mode:** 🤖 AFK · **needs:** BT-01 · **blocks:** BT-14

## Why
The README is written for one reader who already knows the project. A stranger needs to get from
"downloaded a zip" to "working app" without asking anyone.

## Slice
Documentation only.

## Visible result
A README that answers, in order: what it does, will it run here, how do I open it, what does it
want from me, what can it not do.

## Done when
It covers: what BarT does (screenshot comes with BT-14), the macOS 26 requirement, how to open an
unsigned app, both permissions and their purpose, **that every update requires re-granting them**
(PRD §2), the known limits (main screen only, macOS-pinned items immovable, private APIs can break
with any system update), the absence of telemetry and network access, and the licences from BT-01.

## Files
`README.md`

## Done 2026-09-18

Rewritten for a stranger, in the order the issue asks for: what it does → will it run here →
installing → what BarT asks for → using it → ⌘-drag → what it cannot do. The build instructions
moved to the back, where they belong for a reader who is not going to build anything.

**The "both permissions" in the list above is one permission now.** BT-15 removed the accessibility
one; only screen recording is left, and the README says so explicitly rather than leaving a reader
who heard otherwise wondering.

Claims checked rather than repeated:

- *No network access* — verified by grep: not one networking symbol in the source, the only `http`
  in the whole app is a URL in a comment. The draft also cited "no network entitlement", which was
  cut: BarT is unsandboxed, where that entitlement restricts nothing, so citing its absence would
  have been theatre.
- *Apple Silicon or Intel* — cut. There is no Intel machine here to stand behind it.
- The Gatekeeper path (right-click → Open, then Privacy & Security → Open Anyway) is written out,
  because the double-click only offers a Cancel button and that is where a stranger stops.

The licence section now matches `THIRD-PARTY-LICENSES.md`: the Ice implementation is gone, what
remains is verified private CoreGraphics *signatures*, and GPL-3.0 stays regardless, because a
licence change is a deliberate act rather than a side effect of a deletion.

Two things BT-14 has to fill in: the screenshot placeholder, and the release link the install
section points at.
