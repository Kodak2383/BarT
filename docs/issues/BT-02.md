# BT-02 — README for a public audience

**Mode:** 🤖 AFK · **needs:** BT-01 · **blocks:** BT-14

## Why
The README is written for one reader who already knows the project. A stranger needs to get from
"downloaded a zip" to "working app" without asking anyone.

## Slice
Documentation only.

## Visible result
A README that answers, in order: what it does, will it run here, how do I open it, what does it
want from me, what can it not do.

## Done when
It covers: what BarT does (screenshot comes with BT-14), the macOS 26 requirement, how to open an
unsigned app, both permissions and their purpose, **that every update requires re-granting them**
(PRD §2), the known limits (main screen only, macOS-pinned items immovable, private APIs can break
with any system update), the absence of telemetry and network access, and the licences from BT-01.
